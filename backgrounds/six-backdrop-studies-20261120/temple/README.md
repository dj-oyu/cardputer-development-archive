# Vaporwave Temple

Editable classical gallery with cyan-and-magenta lighting, a geometric sunset disk, a tiled reflective floor, and a lavender scattering volume. It is a static character-free backdrop.

Open `temple.blend` and render frame 1 in Cycles to generate `temple-240x135.png` (opaque RGB, 240×135). To rebuild from code: `blender -b --python-exit-code 1 --python build.py -- temple`. Append `--draft` for a faster check.
