# Cardputer backdrop follow-on looks

Three revised Blender backgrounds. Render an opaque 240×135 still, then use the
[RGB565 encoder and native harness](../dusk-bay-pathtraced-01). The displayed
comparisons use firmware PR #135's rendering and compositing code on the host
and the same Cloud AYNM at a fixed frame, scale and camera. These are not
delivered as firmware builds or physical-device timing measurements.

- **Pipe Dream:** no end wall; repeated paired instrument bays and diminishing depth.
- **Dinosaur forest:** built-in Geometry Nodes for fern/cycad colonies, visible close fronds.
- **Vaporwave Temple:** flat rectilinear near grid, depth-gated wide-angle distortion
  in the distance, sun clear up top with progressive nonlinear lower slits.

The other environments, including the original Macintosh desktop, are not changed.
