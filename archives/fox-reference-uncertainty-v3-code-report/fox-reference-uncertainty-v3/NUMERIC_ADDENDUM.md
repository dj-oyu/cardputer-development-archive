# Pre-render numeric contract addendum
No new reference image has been generated or inspected. Original plan hashes are retained.
Authoritative image entry points require uint8 PNG arrays. Paired luma numerator is 2126*dR8 + 7152*dG8 + 722*dB8, denominator 2550000. Threshold numerator is exactly 20000; equality is inactive. CI is computed on these integer numerators, then reported in normalized Y units. No threshold epsilon. All-seed consensus and CI are both required. Stable IoU uses the classified bright/dark masks directly, never reclassifies a rounded difference of mean RGB. Pooled comparison uses sum of numerators against 8*20000. RMSE/amplitude use mean numerator / denominator. Candidate decoded RGB565 stays float64 at original precision, never rounded to PNG8, with the existing float64 luma threshold 2/255. Reference-only runs contain no candidate metrics.
Generic float functions remain synthetic/debug helpers, not authoritative PNG entry points. Color CI precision uses each PNG channel normalized by 255.
