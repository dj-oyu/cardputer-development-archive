## Scope and API

Add opt-in metadata_bytes(model), node_bytes(model,node), and init_segmented(model, metadata, metadata_bytes, const span *slots, size_t count, owner, generation, out). Each input descriptor is {void *data; size_t bytes}; descriptor ownership ends after successful init. By-value scalar arguments avoid another retained configuration object. Metadata comprises aligned unchanged states plus a copied pointer-only node table. All per-node caches remain independently live until dispose. arena/arena_bytes describe used metadata in segmented mode; a final bool identifies the mode. All consumers must recompile; host padding is not binary compatibility or target32 proof. Legacy init/layout and mutation/evaluation/borrow lifetime remain unchanged. Epoch is mutation-only.

Before writes validate model/node count, metadata and descriptor count/capacity/alignment, overflow-safe address ranges for metadata/descriptor/output/model/cold and every used node span. Check all writable spans pairwise and versus immutable model/cold, output and input descriptor. Validate the complete batch before clearing states or node spans, copying pointers, initializing nodes, and publishing one local result. Keep constant-size loop temporaries, never a node table on stack. Retain only pointers, derive immutable slot lengths on demand. Protect full used metadata and every slot through centralized storage_overlap for every prior arena overlap guard. Existing excess-capacity semantics stay used-byte based. No fallible action after commit starts. Caller owns allocations and must preserve immutable cold/model and all used spans to dispose.
