# Private composed control/render proof

This candidate composes current implementations without changing the public API or asset format:

- Unchanged public AyatsuriMotion and byte-identical generic AyatsuriControls companion.
- Private source-control mapping and strict real QuickJS native packet validation.
- Runtime snapshot build into an acquired writer slot, publication, renderer pin, retirement.
- Actual scene renderer using the clean optimized cutout compositor with unchanged general fallback.
- Two independently leased immutable strips, mocked delayed/LIFO/inline transport, exact completion.

## Results

- Host O2 and ASan/UBSan: complete original control regression plus late submit failure, exhausted two-strip pool, inline completion, close during flight, and rejection after close. Each run retires 1,230 exact tickets and rejects their 1,230 duplicate completions.
- Nine actual motion samples at 0–1000 ms in 125 ms steps: every 64,800-byte RGB565 host image equals the prior motion reference.
- Official existing ESP32-S3 QEMU/IDF toolchain: one completed nine-frame run, 306 exact strip completions and duplicate rejections. Every captured QEMU byte equals host and prior reference. See validation.json and qemu/run-ready/run-metadata.json.
- Clean optimized compositor: 3,000 deterministic reference differential cases, including fractional fallback, invalid alpha, errors, depth/ties, backgrounds, batch/layer limits, status and atomic output preservation.
- Unchanged generic companion Node regression passes.

## Ownership

Only one synchronous JS/backend owner calls the bridge. Renderer scratch is exclusive for an entire render. Publication of a provisional pool slot makes it available for renderer pinning; it does not update the backend's latest key or returned hash. The latest key/hash changes only after successful rendering and completed mock transport. A failure retires the candidate while preserving the previous latest hash and JS state. Submitted partial pixels are not undone.

The transport receives ownership of a pinned ticket before submit. Even an unknown/error result retains the immutable borrowed pixels until exact completion. The mock checks every outstanding strip byte against its captured contents before completing it. LIFO pumping intentionally reorders acknowledgments. Pool exhaustion never flips a static slot. Close rejects new work and keeps existing borrows alive; finalization drains the synchronous callback source, marks it joined, and verifies both pools drained. Storage is static and is never freed or reinitialized while callbacks can run.

## Scope and limitations

This is a synchronous QuickJS bridge plus **mock transport** proof, not production board integration, asynchronous JS, hardware DMA, or an AYNM-format change. Crosscore lifetime stress belongs to the separate lifetime candidate, not this run. No physical hardware, AF_UNIX socket, public push, CI, or user parallel-core branch was used or modified. Source images and shared source candidates were read-only.

ASan/UBSan ran with detect_leaks=0. An additional LSan attempt could not complete because LeakSanitizer reports this environment uses ptrace; do not count leak detection as passed. The first direct QEMU invocation failed to load libslirp before launching a guest. The existing official wrapper supplied its existing library path; the completed run is run-ready, not run.

## Reproduce

Run from the workspace root:

- python fox-product-composed-20261111/private/build_test.py o2
- python fox-product-composed-20261111/private/build_test.py san
- node fox-product-composed-20261111/generic/test_controls.cjs
- python fox-product-composed-20261111/verify.py

QEMU project configuration is generated by configure_qemu.py. Use the existing qemu-esp32s3-20261111/idf-env.sh, build in this candidate's qemu directory, and the existing bounded run_qemu.py runner with qemu-esp32s3-20261111/bin/qemu-system-xtensa. Existing run evidence is retained; choose a new output directory for an intentional rerun.
