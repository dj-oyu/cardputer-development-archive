# Separate host floor-direct core

Only transport/bounce.c, bounce.h, pixel_transport.c and pixel_transport.h differ from frozen core-A production. All physical, visibility and product files are byte-identical; the original core is untouched. This adds no physical render, image fitting, public/device/model changes or frame HDR allocation.

The owned ground descriptor appends three linear rho doubles and mode3. Modes0..2 require canonical rho0. Mode/ID/range/Le replacements increase emission generation; changed floor rho increases material generation. Legacy bounce_eval rejects mode3. The explicit bounce_eval_floor_experimental prepays the independent host floor-work contract. fox_transport_context.floor_work enables dispatch; NULL remains legacy. last_result commits together with aggregated counters and is valid for the immediate successful sample observer, not retained full-frame storage.

Each successful mode3 first-floor hit retains old Le once, then either records zero-rho/tangent skip in the separate work diagnostics or invokes DISK16 at the exact hit using an outgoing-facing raw geometric normal. No native orientation sign, placeholder rho, additional floor world, secondary floor emission or recursive bounce is used. Floor reflection has its own result channel and counters. Black-floor mode3 memcmp matches the entire mode2 result, including old counters and zero new result fields. All primary/secondary visibility budgets remain cumulative and unchanged.

Host work reservations: shader128; tagged floor hit192; invoked fixed48-kernel evaluator12000. Global maxima17241 shaders/71667 floor hits, total875970912. Initializer accepts narrower per-case bounds. Categories and total may be capped lower. Capacity checks precede work, evaluation reservations are not refunded, and budget failure never publishes result/last_result. These are source-level semantic reservations, not machine instructions, CPU or device-fit claims. Visibility routine admission/traversal remains represented by separate VIS ray/node/triangle quotas.

Reproduce with sh floor-tests/run.sh. New bounce and pixel-callback fixtures pass O2/Werror and O1 ASan+UBSan (LeakSanitizer disabled under previously documented environment limitation). Existing four transport synthetic fixtures pass unchanged. Coverage includes both physical floor sides and windings, tilted-plane independent plane-intersection/helper reference, blockers, unchanged Le, zero disk emission without query skipping, light-power scaling, source descriptor ownership and retained scenes, changed-rho generation, invalid rho and normal values, exact tangent helper behavior, mode gate, all10 work-category exhaustions, total/count caps, partial visibility failure with retained prepaid work, overlap rejection, whole-result black compatibility, and last_result/counter/output atomicity on descriptor mismatch or aggregate overflow. The tangent helper case tests an exact zero dot; no claim that ordinary nondegenerate nearest-plane hits can have exact tangent incidence.
