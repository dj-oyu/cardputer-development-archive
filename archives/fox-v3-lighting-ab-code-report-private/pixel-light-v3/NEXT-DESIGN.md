# One proposed visibility design, not implemented
Keep current pixel path experimental. For a host-only next causal arm, copy immutable occluder triangles into a separately owned, bounded scene object with generation ID; snapshot retains that object by explicit ownership. Scene build depends on complete evaluated geometry/pose, light sample positions and ray epsilon. Any mutation rebuilds a new generation; old snapshots retain old generation through disposal/render completion. Do not reuse pose-baked visibility or original resident Blender BVH as a dynamic implementation.
Use the same DISK16 samples and opaque two-sided ray contract. Query visibility per intermediate winning pixel/sample, with scene-scale fixed epsilon. No world visibility or GI additions. Exact scene identity and generation are copied in submission; reject stale/missing generation rather than fall back.
