# Root-rigid pose lifecycle experiment

Scope: a private host harness over unchanged current lid8 AYNM and existing C APIs. This is a sequential discrete-pose lifecycle test, not skeletal skinning, smooth animation, a new rig, a device result, or a new formal60% score. AA is OFF; the separate selected-boundary AA pose path remains unverified.

Fixed source-up yaw: identity, +15°, -15°, identity return, absolute root targets about source/world origin. Source+Z axial yaw maps to native+Y through mirrored B=(38x,-38z,-38y). Original world lights, world illumination, ground geometry/Le, source material constants and both cameras remain fixed. Angles are not reduced after seeing capacity or images. Yaw preserves height and rigid geometric layer relationships in exact mathematics; float residuals and changed rendered visibility are reported separately. It does not implement a floor-contact or joint solver.

One persistent instance per camera/order chain. Preflight evaluates/builds all four fixed states, retaining the initial owned scene/snapshot while releasing each later candidate. Rendering then uses retained initial, rebuilds/renders the two yaws and return, disposes/poisons original instance/model inputs, and replays initial with its original bindings. Explicit evaluationSequence records this ordering. Every complete rendered frame has its own unchanged cumulative per-frame budgets across bands; experiment-wide totals are separate.

Old identity RGB/depth/snapshot equality is an immediate C gate before any yaw rendering, backed by externally pinned old-native control files. They are used only for equality after rendering, never as image inputs to shading or target selection. Return and old replay must match initial bytes. Forward/reverse image/depth comparison covers all five outputs per camera.

Bindings: tokens are caller-issued and are not authentication of independently supplied geometry. The adapter constructs world geometry, normal/material attributes and snapshot from the same evaluated epoch and records content fingerprints. Rotated context plus old differing snapshot must be rejected. Identity-return bytes can legitimately equal original bytes; adapter provenance and stale-generation rejection are distinct from content-hash rejection. Borrowed patch/depth views are never dereferenced after mutation; stale-epoch calls are tested for rejection and unchanged outputs.

Lifetime: at most two owned sets, initial plus candidate. Existing per-scene caps remain unchanged; the diagnostic lifetime reserved cap1703936B is their two-set sum, not increased per-frame/per-scene quota and not device fit. Model/arena, construction scratch, reference-comparison arrays, frame-set controls and band scratch are reported separately. Failed candidate build must leave initial usable, with exact cleanup and no double release. Mode5 exact normal-pair compression and mode4 fallback eligibility/bytes are measured per pose, not assumed from identity.

Author and independent fresh O2 execution completed all four chains /20 frames. Source/lifetime admission and numeric review passed. One additional ASan/UBSan front-forward physical chain also passes through disposal and old-snapshot replay. All planned review stages are complete.
