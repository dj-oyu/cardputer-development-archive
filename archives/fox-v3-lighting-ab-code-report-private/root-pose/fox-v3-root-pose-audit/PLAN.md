# Host root-rigid-pose lifecycle experiment, v1

Fixed before images: current frozen lid8 AYNM; AA OFF; normal-pair opt-in ON; baseline material/world/three disk lights/ground Le and geometry unchanged. Two existing cameras, each forward/reverse packet ordering. No new rig, skin, joints, morph, source edits, production API changes, ref score changes or device claims.

One persistent ayatsuri_model_instance per camera/order chain. Four sequential root targets: identity, native Ry(+pi/12), native Ry(-pi/12), identity return. Position(0,0,0), other rotations0, scale(1,1,1). Pose input angles narrowed once to float. Existing transform T*Rz*Ry*Rx*S, native B=(38x,-38z,-38y): source-up yaw about source +Z corresponds to native +Y axial rotation because det(B)<0; native positional up is -Y. Pivot is world/source origin (0,0,0), not invented neck/hip joint. Ground remains source z=0; yaw preserves source heights and rigid inter-part distances mathematically, with actual float residuals measured. Face layer geometry/contact is rigidly preserved, not visibility or image appearance. Angles will not shrink in response to capacity results.

Same instance targets/evaluate on every stage; generation owner stays valid. Track mutation epochs, target/evaluation stats and borrowed view invalidation. Never dereference stale borrowed memory. After each evaluation copy entire world mesh geometry and front/back SNORM/material attributes; build new owned visibility and transport scenes and snapshot. Pose token monotonically increases for distinct/return transitions; material token also increases when world-normal attributes change although source rho/material constants stay identical. Geometry token may conservatively increase with actual world arrays; light/emission tokens fixed because world sources fixed. Verify actual content fingerprints rather than treating tokens as proof.

Identity initial must reproduce frozen old RGB/depth/snapshot exactly before rotated quality diagnostics. Identity return must reproduce initial geometry/attributes/snapshot/RGB/depth bytes while having a later mutation/pose generation. Each distinct pose is rendered forward/reverse with exact RGB/depth equality. No formal v3 score against fixed-pose references for rotated poses.

Retain initial snapshot+scene+transport set across later instance mutations and disposal. Re-render old initial snapshot with its original binding and independently reset per-frame budgets: old output remains exact. Pass old snapshot to new current binding/context: mismatch must reject before published output. This tests mismatched bound render, NOT a claim that the low-level fox_pixel_bind API authenticates independently supplied geometry: that API can bind a caller-supplied snapshot and relies on caller provenance. Harness checks recorded scene/snapshot generation/content correspondence before bind; no artificial claim of stronger existing API.

At most two owned snapshot/visibility/transport sets coexist: retained identity and current candidate. Release a noninitial current set before constructing the next. Distinct source temporary arrays are poisoned/freed after owned construction; after final copy dispose instance and poison/free arena/model before retained-old replay. No stale input pointers retained. Lifecycle counters/aliases/refcounts validated where APIs expose them.

Per-frame unchanged limits: snapshot65536; legacy bbox work8000000; direct rays/nodes/triangles 1M/100M/50M; transport20M/800M/300M; visibility scene524288B; transport scene262144B; max geometry2048tri/4095BVHnodes. Each full frame accumulates across all bands. Reject a whole frame on admission/render failure, no partial quality result, no subset rescue. Whole experiment counters and frame count retained separately; independent frames are not represented as one frame budget.

Report actual used sizes, plus separately model cold data, instance arena, construction world/index/attribute scratch and renderer band scratch. No AA workspace or full HDR frame.

Before actual rendering: source/harness diff and syntax/fixture review; append/admission for all fixed poses without changing caps. If any pose fails, preserve failure and stop quality progression rather than adjust yaw/geometry/codec/quota. Tests include stale epoch view rejection, invalid target batch atomicity if reused existing APIs, correct old replay, mismatched binding reject, owned-data survival, root height/rigidity residuals, and no hidden global source/light edits. No CPU comparison until reviewer heavy work has ended.

Output: private raw artifacts retained for independent validation only. Save code/tests/aggregate report/metrics/lifecycle/cost/pins allowlist, excluding geometry/models/snapshots/per-pixel dumps/images. Original source and existing experiment directories stay immutable.
