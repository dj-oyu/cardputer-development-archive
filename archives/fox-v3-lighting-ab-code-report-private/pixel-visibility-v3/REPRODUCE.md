# Reproduce private host comparison
Requires original private model/reference inputs at paths pinned in inputs/candidate-config.json and the separately retained frozen fox-reference-uncertainty-v3. They are intentionally excluded from this bundle.

From workspace root, choose fresh output folders:

HONE_LINEAR_LIGHT=1 HONE_PHYSICAL_LIGHT=1 HONE_PIXEL_LIGHT=1 HONE_PIXEL_VISIBILITY=0 python fox-v3-pixel-visibility/code/run.py fox-v3-pixel-visibility/new-off
HONE_LINEAR_LIGHT=1 HONE_PHYSICAL_LIGHT=1 HONE_PIXEL_LIGHT=1 HONE_PIXEL_VISIBILITY=1 python fox-v3-pixel-visibility/code/run.py fox-v3-pixel-visibility/new-on
python fox-v3-pixel-visibility/scoring/score_candidate.py fox-v3-pixel-visibility/new-off/candidate-manifest.json --output fox-v3-pixel-visibility/new-score-off
python fox-v3-pixel-visibility/scoring/score_candidate.py fox-v3-pixel-visibility/new-on/candidate-manifest.json --output fox-v3-pixel-visibility/new-score-on
bash fox-v3-pixel-visibility/test_all.sh /absolute/fresh-test-output

code/run.py copies sources/inputs first, records hashes, uses actual C with fixed compile flags, evaluates whole geometry and actual owned shared-depth rendering, checks reverse order exactness and input immutability. No render completes successfully after traversal budget exhaustion. Partial band/files are not accepted by evaluator without successful exact metadata/manifest. Budget does not reset between bands.

Tests use no private geometry: synthetic fixtures are generated by existing model tools. LeakSanitizer unavailable under this runner; ASan/UBSan and explicit allocation balance cover tested failure paths, not a general leak-free claim.
