# Residual eyelid / socket attribution, eyeB

Read-only diagnosis using all previously fixed sourcebbox32²rays, both eyes, front/oblique and the two former holdout directions. Those directions are now known validation, not unseen tests for a future candidate. No candidate mesh/model/image/reference/threshold was changed.

Dominant remaining eyelid problem is the unchanged reduced eyelid curve, not new B white/iris occlusion. Across eight eye/view groups B loses296 originally visible eyelid rays;245 (82.8%) do not intersect the reduced eyelid at all. These surface-miss counts are identical to stage2 in every group (33,28,37,26,34,24,33,30). Remaining51 intersect the lid but another object is closer, mostly unchanged socket/anatomy. In B, white is no longer the blocker on these lid-loss samples. Correctly visible lid counts remain4,11,5,9,5,11,4,15, far below the original.

Source-only curve check: actual original upper lids are open Bezier tubes,5control stations, radius.013, no endcaps. Read-only fixed64parameter samples per Bezier segment gives257centreline samples per side. Distance from that centreline to current reduced eyelid surface reaches .061975/.054468, about4.77/4.19times radius;145/116samples exceed radius. This is independent of camera, light or image colour. It is a finite nearest-distance diagnostic, not a global surface Hausdorff bound, and radius is not a new formal acceptance threshold. Original source/GLB hashes are recorded and remain unchanged.

Socket overexposure has a separate interaction. Side−1 extra socket winners increase229→271, while side+1 decrease263→205: all-side total actually improves492→476. Every NEW socket winner in B was a white winner in stage2. Since socket/lid geometry is byte-unchanged, changed white geometry is necessary for this newly exposed set; this does not prove iris has no interaction. Some old white coverage was hiding the faulty lid or socket, and some was correctly showing white. Do not restore a broad white shape merely to hide the underlying lid defect. Counts distinguish original-eye-white, original-lid and other original winners in summary.json.
