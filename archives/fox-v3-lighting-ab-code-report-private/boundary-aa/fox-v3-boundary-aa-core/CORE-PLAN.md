# Isolated final-visible-only boundary AA core

This implements the separately authorized PLAN-v2 host experiment. It never changes the default or the semantics of existing renderer entry points. All frozen product files remain identical; `ksn_mesh_depth.c` retains its entire original byte prefix and appends one include. The observed center function is an isolated source copy; successful pixel/stats commit precedes source identity commit.

## API and outputs

`ksn_mesh_pixel_render_boundary_experimental` consumes owned snapshot storage, an immutable 5-byte-per-face original-oriented source identity table, expected FNV table/snapshot fingerprints, a conservative category ledger, caller-owned RGB565 and center depth, and caller-owned workspace. Caller initializes RGB black exactly as the old host adapter does. `fox_transport_render_boundary_experimental` uses the original static transport shader callback, its original retained scenes and the same two cumulative budgets. No lighting implementation is duplicated.

Optional output-only sample observers receive each selected sample, including nohit black, with exact sample index, owned record offset, face, node, source identity, physical side, sample depth, actual barycentrically reconstructed position/normal/rho and unclipped linear RGB. Observers retain no pointers; failed diagnostic I/O aborts publication. Diagnostic I/O and external storage are separate from core accounting.

Output depth remains center depth everywhere. Workspace exposes center IDs and the frozen target bitset. Sample support is observable separately. All final RGB must stay private until true return plus `report.complete`; false means discard partial outputs. Both transport budgets retain consumed work on failure and are never reset by this API.

## Identity and unconditional validation

The pinned table is `(records+1)*LE16 offsets` followed by `faces*(original ordered local indices[3]+sourceID LE16)`, exactly 7930 bytes for the fixed asset. Each source ID is 0..91 and node is 1..54. A combinatorial unordered-triangle key uses C(max,3)+C(mid,2)+min in 0..4959. A uint16 generation-tagged map is cleared once: upper byte is node ID, lower byte is face ordinal+1. This proves duplicate rejection and O(1) matching even when records and faces are reversed, without quadratic search or repeated table clears. It shares the HDR band's memory before rendering. Original-to-owned permutation parity must equal the owned physical back-side bit; cyclic permutations retain parity.

Every record, including hidden and non-target records, goes through unchanged `co_read` validation of all lengths, modes 4/5, reserved/padding fields, finite projected/world fields, SNORM domain and vertex/index constraints. Every triangle area and identity is checked before center or subpixel shading. Duplicate/missing nodes, duplicate table or owned face keys, incorrect side/winding, unmapped source IDs and fingerprint mismatches reject. Only owned snapshot offsets are stored as sample winners; maximum storage remains 65536, offset fits uint16 and face index fits uint8. No model/arena borrow survives.

## Stage ledger, guard accounting and memory

Historical center bbox49 is retained verbatim as its own reservation category. It is not a CPU-instruction or timing-equivalence claim. All other categories are the newly authorized bounded stages. Each counter guard has an additional explicit reservation and observed count. Bbox guards run once per nonempty triangle bbox; bbox stages are incremented for every actually visited point, including non-target mask tests. Individual candidate/dispatch charges happen before their work. No observed counter is silently reset or allowed past its reserved bound. The old center ledger is a reservation by definition, not measured instruction execution.

The original PLAN category bounds are unchanged. Additional bounds are: generation-key clear 9920 bytes, identity fingerprint 8192 bytes, snapshot binding fingerprint 65536 bytes, admission/phase control 4096 stages, counter guard dispatches 310000, and a separate final-output pixel scan 32400. Totals are front 7950858 and oblique 7725926, both below 8000000. Physical direct/transport quotas and existing scene caps are unchanged. An exact geometry-only all20 constant-shader fixture observed maximum 245819 guard dispatches. Replacing its actual center successes by the conservative center bbox bound and actual sample hits by all-target-hit bound yields 294417 front and 283926 oblique, both below the 310000 guard reservation. This is separate from later physical-transport completion testing.

`sizeof(ksn_aa_workspace)=137312` on the tested host ABI. The extra transient stack reserve is 8192, so the additional core bound is 145504 <=147456. Full retained caller outputs are separately 194400 bytes. Immutable identity is separately 7930 <=8192 bytes. No full-frame HDR array exists. Eight-row HDR storage is reused for the identity map and the last band clears/scans only its seven valid rows. Compiler stack-usage reports are retained, with new core/transport call frames and unchanged physical/visibility frames below the stack reserve; custom diagnostic observer and C runtime internals are separate existing/diagnostic costs, not a device-memory claim.

## Error semantic limitation

`tests/test_hidden_failure.c` demonstrates a real old-error-equivalence FAIL: the old full center succeeds, an intermediate hidden surface has a zero normal at true (+.25,+.25), sequential old subpixel shading fails, final-visible-only shading succeeds. The reverse old traversal also succeeds. An injected shader failure gives the same disagreement. This is retained and is explicitly permitted ONLY by the new host experiment's error contract. Intermediate lighting-domain failures and quota costs of discarded shading are deliberately not detected. Final-sample normal/domain/shader failures and any actual cumulative quota exhaustion still fail the entire new frame. No old-success equivalence is claimed.

## Executed checks and remaining gates

Synthetic unit fixtures and ASan/UBSan cover frame exterior sentinel, black nohit fixed-four denominator, linear HDR averaging before encoding/clamp, top-left shared diagonal, depth ties/first winner/reverse order, center depth exactness, non-target RGB identity, every 21 ledger category exhaustions, table mutation/duplicate/source-side rejection, mode4 fallback plus mode5, source poison/free, final invalid normal, unconditional hidden nonfinite rejection and observer failure. LeakSanitizer itself is unsupported under this container's ptrace environment, so only its leak scanner was disabled.

All20 fixed owned snapshots passed source mapping, physical-side parity and exact independently recomputed target masks using a constant shader. These are not actual physical renders, CPU measurements or quality scores. Full all20 physical transport, adapter atomic publication, independent sample proofs, scoring and CPU evaluation remain with the parent integration task.
