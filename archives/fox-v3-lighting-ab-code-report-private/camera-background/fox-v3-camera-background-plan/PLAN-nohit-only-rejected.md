# Camera background: preimplementation contract (draft, admission pending)

Base: frozen A2 rho-affine quarter-offset renderer, current lid8 geometry. The old floor-reflection ON experiment is not included. No source/model/reference/mask/threshold/default changes, no AgX, new filtering, sample density or exposure tuning. This plan is not permission to bypass a failed original budget.

## One independent intervention

For each non-target pixel, retain its original character center hit and RGB unchanged; only a character center miss resolves background. For each fixed AA target, retain all four original character samples; replace only no-character sample black with physical background HDR before the existing equal quarter mean and single sRGB565 encoding. Geometry-selected mask is never recomputed from color or background. Character depth, coverage, source IDs, shape errors and missing original foreground remain unchanged. A background-filled missing character is still a geometry failure.

Background is finite authored floor geometry (two triangles, source XY extent -100..100, Z=0) or true scene miss. Floor HDR = source-linear rho * existing three-DISK16 visible direct Lambert irradiance normalization + source-linear rho * constant-world radiance + source floor Le once. Reuse existing physical evaluator normalization, without a second rho/pi. Report these three components separately. Constant-world floor illumination is explicitly unoccluded Lambert; no secondary ray, reflected character, floor specular/Fresnel, full Principled energy partition, indirect GI, or old floor-reflection arm. A true scene miss returns source world radiance itself, not rho-weighted lighting. World display radiance and floor world illumination are distinct counters/components even when based on the same constant source.

Source rho and albedo*.6 float values are the already audited source material constants, never RGB565/sRGB recoding. Le is unchanged by albedo. Floor receiving normal is source geometric Ng oriented against incoming camera direction; exact tangent is a miss. Direct shadow uses the same owned character-plus-floor BVH, existing endpoint epsilon 1e-5 world, no new normal offset or self exclusion. Invalid/nonfinite/near-parallel overflow is failure, not silent world fallback.

### Clipping, intersections and proposed storage

A finite floor intersection outside the authored camera clipping interval, a negative camera-ray parameter, a point outside the finite triangles or an exactly parallel ray is a scene miss with a recorded reason. Nonfinite arithmetic is failure. No near-parallel epsilon is introduced. Native depth equals rounded-forward dot (nativeWorld-target), larger is nearer; comparison is performed in that common depth coordinate. Camera axial clip distance includes the target-to-camera offset and is distinct from native depth. The exact inverse uses all12 float projection coefficients Q32/t32 rebuilt with actual identity mesh_packet float operations, not a rounded basis transpose or unscaled basis with a double zoom. Ray points are Q32^-1([x,y,d]-t32); camera-plane d is the same projection applied to native camera location. Source axial clip distance is dot(sourcePoint-sourceCameraOrigin, sourceUnitView), with normalized negative camera-matrix third column. Store round-trip and raster-P discrepancies; do not call these rounded receivers identical.

Proposed new host-only callback API resolves nohit HDR into the existing band accumulator; non-target center misses are processed once and encoded separately. No additional full-frame HDR array is planned. Old API has no callback and remains unchanged. Exact owned descriptor, callback state and stack sizes, alias validation and work charges are pending implementation design; a small anticipated payload is not an admission certificate.

The ordering preflight includes every center plus every selected quarter sample (41,940 front /41,964 oblique), including target centers even though those are not background-shaded in the combined result. This preparation domain is distinct from both background render domains. Shared floor diagonal counts one hit; native float depth equality gives character priority. Per-sample local HDR starts black and is replaced only by a successful callback value, then added once to the existing four-sample sum. The callback output is locally atomic. Caller frame/band buffers can be partial on failure, as in the legacy host experiment; no image publication or completed manifest is allowed in that case. Do not claim whole-frame buffer atomicity.

World precision is fixed to existing physical fox_disk_scene_init: source-saved float Color and Strength read as double, then double multiplication. Baseline radiance [.3499999940395355,.30799999308586123,.2414999950528145], ambient exactly twice for these inputs. Existing A2 FOXDISK1 inputs use the same values and evaluator. This is not an assertion of Cycles closure float arithmetic identity.
