# Threshold warning design (not implemented or certified)

A strict predicate cannot generally retain exact float32 branch parity after finite coordinate or arithmetic quantization. Increasing fractional bits reduces ordinary error, but does not remove a discontinuity. Do not replace the source predicate with hysteresis, softstep, or visually chosen bias.

A future checked evaluator should carry outward-rounded intervals for the difference between its represented result and the declared source-operation float32 result. Coordinate leaves include their exact quantization error; constants, prepared control values and ramp entries include their separate errors. Propagate add/subtract intervals, endpoint product extrema, reciprocal/division extrema only for denominator intervals that exclude zero, and monotone sqrt intervals after the source max(a,0). Include each source float32 rounding error, each fixed rounding error and the actual operation order. A generic relative epsilon alone is insufficient near zero or cancellation. LUT cell uncertainty must include every intersected cell, including both sides of a breakpoint. Mix factor clamps and source min/max are propagated, not removed.

For LESS_THAN(a,b), if the full source-compatible interval for a-b is strictly negative, true is certified; if its lower bound is nonnegative, false is certified. Otherwise emit an explicit ambiguous-threshold flag. GREATER_THAN uses strict positive versus nonpositive analogously. Equality is not treated as safely on either side without the correct strict rule. Preserve source exact-zero division semantics separately from a nonzero denominator quantized to zero; the latter rejects. If an interval includes zero, flag or use a separately authorized reference fallback, never silently change division semantics. Current reachable denominators are nonzero in the declared control domain; broader controls are rejected.

This directory implements raw margin/operand logging and numerical scans only, NOT the interval propagation above. Those logs do not prove an error bound or catch every possible predicate change. A future certified warning can be conservative and flag points whose branches happen to agree. Finite fixtures and scans cannot certify all controls, all local coordinates, all animation, or image parity.
