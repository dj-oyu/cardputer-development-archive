# Executable three-frame contract

`run_canary.py --prepare` creates a frozen review artifact without starting any render. `--run baseline <reviewed SHA>`, `--run q16 <same SHA>`, `--run q20 <same SHA>` execute one stage each, only in that order. The preceding stage must have a PASS manifest. Every attempt reserves a fresh prefix by exclusive command.json creation before the unchanged renderer's own reservation. Existing artifacts block retries. All full execution stays pending parent review of the exact freeze hash.

Fixed output prefixes under `plan/canary-output/`: baseline-front, q16-front, q20-front. Each subprocess has a predeclared300-second upper wall-time allowance (old frame about20s); timeout is a preserved failure, not a retry. Stop conditions include nonzero exit, stderr, hash change, guard/cap failure, preflight mismatch, incomplete reports or baseline output difference. Failure leaves the attempt and artifacts in place.

Source freezing includes every compiler dependency and stack output; original memory/named-stack evidence; all metadata-pass input freeze dependencies; generated headers and ledger contracts; exact runtime model/ground/light/camera sources; bridge/AYFQ provenance; baseline references; runner/comparator/build/generator code; and all three predeclared argv/environment mappings. Hashes are checked before and after every render. Canonical model paths come from independently verified preflight commands.

Baseline requires byte equality of `.snapshot`, `.f32le`, `.targets.u8`, `.hdr.f64le`, `.u16le`. All non-timing fields across9 JSON reports must match, except explicitly rebinding `background.inputJSONSHA256` to new CANDIDATE_INPUTS.json. Expected timing exclusions only: main transportBuildNs/visibilityBuildNs/appendNs/evaluateNs/hostRenderNsFirstFrame, background and row backgroundBuildNs. Unknown fields or other differences fail baseline admission.

Candidate guards are not waived for visual changes: own snapshot/depth/mask must equal independent preflight; quarter hit/target/shader counts, floor counts/limits, background actions, scene category reservations, world work and producer+depth budget must match independently prepared facts or stay within original declared bounds as appropriate. Every reported per-category used/limit and observed/reserved pair is validated. Existing unchanged renderer checks and explicit complete reports remain mandatory. Report differences are fully retained instead of blanket-discarded.

Candidates measure HDR max/mean/RMS, quantiles and relative errors above1e−3; boundary and baseline-depth character/background subsets; RGB565 changed pixels/channel steps; depth and target-mask changes. The subsets are diagnostic masks, not inferred per-ray floor categories. Geometric primitive-winner differences remain in preflight results. No numeric quality threshold is invented after seeing output; this is an isolated measured canary, not deployment approval. All baseline invariants still gate success.

Shadow equivalence is NOT claimed: aggregate renderer visibility/transport counters are retained as report differences, and exact metadata already proves q20 primary ground→character reclassification. Per-query aligned direct-light shadow comparison requires a separate observer/replay design. No shader instrumentation is added by this canary.

`compare_canary.py` original-vs-original selftest passes all raw, report, independent preflight, floor/background/scene limit and numeric checks. Header checker passes three genuine rows and wrong-count/unknown-nonzero-hash rejection. All16 stack-file function maps are exactly equal to the old build. No new/growing functions or runtime allocation/layout changes.
