# Independent world-reflection metric admission

This analysis is read-only with respect to renderer, captures, source geometry, reference, profile and every pre-existing artifact. It never launches a renderer or display transform. New files are code, tests, pins and aggregate reports only.

The single contrast is world OFF versus world ON while existing floor-direct reflection remains ON and the completed camera background and AgX profile stay fixed. World OFF must match every completed prior floor-ON HDR, legacy565 and AgX565 byte buffer and unchanged character depth before any world-ON scoring. Fresh OFF formal values must exactly reproduce the previous floor-ON formal aggregate. Failed, rejected, partial, duplicate or hash-mismatched runs cannot score.

Both arms use unchanged original formal v3 code, reference, two views, five conditions, eight reference seeds, threshold 2/255, reference-only stable/uncertain partitions and all 13 fixed attribution domains. Every all10 color MAE/RMSE, all8 response metric, bright/dark IoU, FP/FN, reversal, active-to-inactive and unknown count is retained. All conditional statuses and nulls remain unchanged in meaning; global acceptance remains NOT_ESTABLISHED.

A complete-manifest pin inventory must be supplied before scoring; linked source/input/output files are independently checked and rechecked before completion. Raw arrays are used only in memory. Saved formal uncertainty locations are replaced by counts and canonical hashes without changing calculations. Saved aggregates use deterministic gzip, and the result includes decompressed hashes and byte counts.

Ambient response must be reported alongside color improvement. Every numeric regression is retained without claiming that correlated scalars are independent tests, votes, additive contributions or evidence of default adoption. Shape limitations and old resource-budget failures remain separate and unchanged.
