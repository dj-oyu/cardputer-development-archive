# 雲のキャラクター｜輪郭の受け渡し 02

比較動画・確認画像は同梱しない。文中のファイル名は、下記手順で再生成したときの名前。

待機用01は、空を漂う雲らしくゆっくり形を変える一方、Cardputer相当の240×135で差が読み取りづらかった。02では縁がほどける領域と反対側へ形が寄る領域を広く、強くした。基準カメラ、照明、時間、顔の動き、手・彩雲の動きは01に揃えた。肺のように体全体を膨らませたり、内部の丸い塊をばらばらに動かしたりしない。弾む別モーションは変更していない。

- `cloud-idle-wind-02.blend`: 10秒の待機ループ。01の原本は別管理。
- `idle-wind-02-ab.mp4`: 01と02を固定画角・同じ時刻に並べた10秒（8fps）。 `idle-wind-02-comparison.png` は各240×135の並列画像と輪郭差分。
- `idle-wind-02-validation.json`: 241フレームで顔、間隔、ループ端を照合。代表8フレームの胴の投影面積は6,424〜6,488px、範囲0.99%。同じ胴の起点に対する輪郭差は最大709px、01は455px。顔パーツの間隔は一定。左右の手・彩雲との投影離隔の最小値は9.41 / 15.59 / 9.04px。
- `idle-wind-02-edge-comparison.json`: 投影胴が横29px以上ある行の左右輪郭を比較。強い局面の90パーセンタイルは旧4pxから新6pxに、後半の複数局面は旧3pxから新5pxへ。急な斜面と画素丸めで出る単一行の極値は見た目の代表値に使わない。
- Blenderでの造形・小画面表示比較。Cardputerレンダラーによる変形や実機FPSは未検証。

## 再生成

```sh
blender -b --python build_idle_wind.py -- ../idle-wind-01/cloud-idle-drift.blend
python3 compare_idle_wind.py ../idle-wind-01
```

比較には01の `frames/` と `mask-*.pgm` が必要。未生成なら01の作成スクリプトを先に実行する。Pillow、ffmpeg、日本語Noto CJKフォントを使用する。

指南書への知見：面積維持と可読性は別の合格条件。面積と顔の維持を確認しただけで終わらせず、旧案と同じ画角・時刻・実寸で並べ、輪郭が広い範囲で何px動いたかを見る。
