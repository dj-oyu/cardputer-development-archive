# 雲のキャラクター｜局所変形モーション

比較動画・確認画像は同梱しない。文中のファイル名は、下記手順で再生成したときの名前。

前版の「全身が傾き、一度に縮む」芝居と別の編集可能な試作。魚群や鳥の群れのように、ふくらむ中心が輪郭を順に移動し、通ったところを収縮が追う。全身を同時に拡大・縮小せず、9つの局所変形に位相を付けた。顔の手前の面は固定し、手と彩雲は胴体とは別の周期で漂う。顔は元モデルと共通。

## 検証

- 24 fps・10秒のループ。輪郭の頂点変形と顔パーツの位置を検査した。
- Blenderの固定カメラ・240×135換算における全241フレームの保守的な輪郭間隔（画面上のバウンディングボックス）は、左右の手 4.1 px / 7.5 px、彩雲 3.3 px 以上。目の中心間隔は試験フレームで不変。
- 同じカメラ・照明の前後比較は `cloud-motion-ab.mp4` と `cloud-motion-ab-contact.png`。図中の中心名は、各時刻の最も強い変形キーを示す。顔の下に見える波及はBlenderの造形検証で、Cardputer側のモーフ対応や実機性能は未確認。
- 原本SHA-256と派生版SHA-256、時系列の変形値は `amorphous-validation.json`。元の .blend は変更していない。

## 再生成

```sh
blender -b --python amorphous.py -- ../v1/cloud-delivery.blend
python3 compare_motion.py /path/to/v1-replay/delivery/cloud-motion-10s.gif
```

比較の再生成には Pillow、ffmpeg、日本語Noto CJKフォントが必要。保存調整の判断では、キャラクターが生き物らしさを必要とするとは限らない。無定形なら、全身のバネ運動を足すのではなく、画面上で「どこがいつ膨らみ、どこが遅れて引くか」を時刻と部位で比較する。
