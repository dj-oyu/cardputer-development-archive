# Cloud character first-pass checkpoint

Editable Blender blockout with floating hands, a separated horizontal iris ribbon, and a 10-second rigged motion sketch. This is a work-in-progress checkpoint, not an adopted model. A Blender camera preview can be regenerated locally; it is not Cardputer output or a performance result. The design reference is not embedded or redistributed.

Build the editable scene with `blender -b -t 2 --python build_cloud.py`; pass `-- --wip` for the blockout settings. Target export uses a separate opaque proxy; no renderer changes or physical-device results are included.
