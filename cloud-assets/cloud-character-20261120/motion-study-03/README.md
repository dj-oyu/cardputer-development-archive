# 雲のキャラクター｜動きの試作 03

比較動画・確認画像は同梱しない。文中のファイル名は、下記手順で再生成したときの名前。

魚群の比喩を、全体と局所の二層に分けて試した版。群全体は外から圧を受けたように狭まり、逆に行き過ぎ、ごく小さい揺り戻しを経て収まる。一方、内側では同じ変形のきっかけが少しずつ遅れて届き、先に開くところと、まだ縮んでいるところが共存する。02のように独立した局所変形だけを回し続けず、全体を一定周期の拡縮にもしない。

- **原本・編集**：`cloud-elastic.blend` 内の胴のシェイプキーとボーンアクション。02は変更していない。目・口の周辺は変形から保護し、手と彩雲は輪郭から離れたまま少し遅れて動く。
- **240×135相当の固定画角**：胴の画面上の幅は待機92.7px、1.33秒で73.5px、1.83秒で105.9px、その後92.7pxへ戻る。1.79秒では全体が跳ね返る途中で、左肩が外へ、右下が内へ動く成分が同時に残る。145フレームで左右の手・彩雲の隙間を検査し、各最小値は6.94px / 3.66px / 3.49px。目の中心間隔とループ両端の胴の形は変わらない。
- **前後比較**：`elastic-ab.mp4` は同じカメラ・照明・時刻の02/03比較（6秒、8fps）。`elastic-ab-contact.png` は静止画抜粋。これはBlender上のアニメと投影の確認であり、Cardputerのモーフ描画、透過、実機性能の確認ではない。

## 再生成

```sh
blender -b --python build_elastic.py -- ../motion-study-02/cloud-amorphous.blend
blender -b --python prior_preview.py -- ../motion-study-02/cloud-amorphous.blend
python3 compare_elastic.py
```

比較にPillow、ffmpeg、日本語Noto CJKフォントを使う。手順書への知見：形が広がる波を求められたとき、個々の山のピーク移動だけで合格にしない。全体の外形にも収縮・反動・収束があるかを固定カメラで測り、同じ時刻に局所が別の位相を持つことを確かめる。
