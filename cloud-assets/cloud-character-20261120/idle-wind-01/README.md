# 雲のキャラクター｜待機時の形の流れ 01

比較動画・確認画像は同梱しない。文中のファイル名は、下記手順で再生成したときの名前。

肺のある生き物の呼吸でも反発でもなく、空を飛ぶ雲の輪郭がゆっくり組み替わる演出。体全体を膨らませず、広い領域の縁がほどける間に別の広い領域へ形が寄る。左の縁と右下、右肩と裾、裾と左肩が少しずつ重なる。内側を個別の球が流れる見せ方は使わない。顔は形と間隔を維持し、手と彩雲はわずかに別の動きで浮かぶ。弾性の03/04と違い、こちらは穏やかな待機用の試作。

- `cloud-idle-drift.blend`: 10秒の編集可能なショット。3つの向かい合う輪郭変形と、小さな面積補正を共通の胴体に適用する。物理流体シミュレーションではない。
- `idle-drift-contour.png`: 実寸の胴のみの輪郭を重ね、外へ出た差分と内へ入った差分を色で比較。光や影は差分に含めない。
- `idle-drift-preview.mp4`: 240×135のBlender描画を2倍表示。8fps、10秒。Cardputer描画・FPSの検証ではない。
- `idle-drift-validation.json`: 241フレームで、顔の間隔、手・彩雲との距離、ループ両端を検査した記録。代表8フレームを240×135の画素中心で胴だけレイ判定すると、面積は6,449〜6,488 px（範囲0.60%）、輪郭の内外が入れ替わった画素は起点比で最大455 px。胴と周辺パーツの画面上の保守的な離隔は最小11.15 / 15.84 / 9.04 px。視点の異なる時の体積や実機性能を示すものではない。

## 再生成

```sh
blender -b --python build_idle_drift.py -- ../motion-study-04/cloud-variable-center.blend
python3 make_idle_preview.py
```

Blender 4.3.2、Pillow、ffmpeg、日本語 Noto CJK フォント。検証用の `mask-*.pgm` と映像素材の `frames/` は生成される。原本04は変更しない。

判断の知見：無生物に「生きているような」動きを付けるとき、最初から生物の機構（呼吸・脚での荷重など）を借りない。何が移動し、何が変形し、何をほぼ一定に保つかを決める。面積を固定して動きまで止まっていないか、固定画角で輪郭差分を重ねて確認する。
