## 再生成

```sh
blender -b --python build_centers.py -- ../motion-study-03/cloud-elastic.blend
python3 compare_centers.py ../motion-study-03/frames
```

比較には03の元フレームが必要。保存されていなければ03の生成スクリプトで `frames/` を再生成する。比較の作成時には Pillow、ffmpeg、日本語Noto CJKフォントも使用する。数字は最も強い姿勢を全フレームから計ったもの。比較画像では8fps表示に最も近いフレームを選ぶ。

判断の知見：開始時刻をずらすだけでは、変形時間しだいで目立つ最大収縮が等間隔に揃うことがある。今回も最初の候補は最大収縮が1・5・9秒に揃った。固定画角で外形の山・谷を測ってから時刻をずらし、意図通りなら比較映像を作る。
