# 雲のキャラクター｜待機モーション 7秒

待機02の10秒を、**再生時間70%の7.000秒**に変更した。元の形、運動の順序、カメラ、照明は変更していない。弾む別モーションには触れていない。共通する始点フレーム1を軸に、リグ・シェイプキー双方のキーフレームとハンドルの時刻だけ0.7倍へ変換した。24fpsの1〜168が再生範囲で、169は先頭と同じループ境界の確認フレーム。プレビューは重複する169を含めず、8fpsの56枚でちょうど7秒。

- `cloud-idle-wind-7s.blend`: 編集用Blender原本。
- 確認用映像は240×135のBlenderプレビューを2倍表示したもの。GitHubに収録せず、必要なら下記の手順でローカル生成できる。
- `idle-wind-7s-manifest.json`: 開き直したファイルを、元版の対応する時刻10点（小数フレーム含む）で照合。全評価済み頂点の最大差は約7.2×10⁻⁷ Blender単位。ループ境界の最大差は約1.2×10⁻¹⁷。形状・リグの41チャンネル、3,321キーを処理。元のハッシュも維持。

編集用のキャラクター全体は三角形換算23,224（背景・カメラ・照明なし。眉と口のカーブを評価済み）。過去の2,019三角形の不透明GLBは別の静止ポーズ試作品で、今回の待機を含まない。今回の動画はBlenderで、Cardputerでの描画・性能の証明ではない。

## 再生成

```sh
blender -b --python retime_idle_wind.py -- ../idle-wind-02/cloud-idle-wind-02.blend
ffmpeg -y -framerate 8 -i frames/frame-%03d.png -vf scale=480:270:flags=neighbor \
  -c:v libx264 -threads 3 -crf 17 -pix_fmt yuv420p -movflags +faststart idle-wind-7s.mp4
```
