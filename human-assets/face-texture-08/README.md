# Human character: facial graphic projection prototype 08

Based on the saved varsity-06 authoring model. Removes the separate modeled eyes, lids, brows, mouth and nose, retaining the skin, ears, hair, clothes and original rig/animation. Uses a single transparent facial image on the existing skin. No geometry is added for face art.

The registered 1024 × 1024 image is packed in the Blender project and shaded as part of the original skin albedo. Orthographic calibration: camera (0, -13, 4.78), width 2.24, target (0, 0, 4.78). UV stays fixed while the head deforms and a rest-space front mask prevents the image repeating on the rear. The facial marks are preserved apart from uniform scale/translation and transparency cleanup.

Blender-only prototype, not an on-device texture export. The straight-on gaze is slightly convergent in this trial, and the flat painted nose has no profile relief. See projection and reopen evidence.
